# Guia de contribuição

Obrigado por contribuir com o projeto da ONG Esperança.

## Fluxo de trabalho

1. Atualize a branch `develop`.
2. Crie uma branch com prefixo `feature/`, `fix/`, `docs/` ou `hotfix/`.
3. Faça alterações pequenas e commits semânticos.
4. Teste todas as rotas e interações afetadas.
5. Abra um pull request para `develop` descrevendo contexto, solução e validações.

## Padrão de commits

Utilize Conventional Commits:

- `feat:` nova funcionalidade;
- `fix:` correção de comportamento;
- `docs:` documentação;
- `test:` criação ou ajuste de testes;
- `refactor:` reorganização sem mudança funcional;
- `chore:` manutenção do projeto.

## Checklist do pull request

- [ ] alteração relacionada a uma issue;
- [ ] interface validada por teclado;
- [ ] contraste e nomes acessíveis revisados;
- [ ] rotas e console do navegador verificados;
- [ ] documentação atualizada quando necessário.
